
An integral 
$$I = \mathbb{E}_f[g(X)] = \int g(x) f(x) dx$$
can be rewritten, using "importance sampling", by using an **proposal** density function $q(x)$:
$$I = \mathbb{E}_q[g(X)f(X)/q(X)] = \int \frac{g(x)f(x)}{q(x)} q(x) dx$$
Then we have two estimators
$$I_1 \approx \frac{1}{n} \sum_{i=1}^n g(x_i), \text{ where } x_i \text{ is generated by } f(x)$$
and 
$$I_2 \approx \frac{1}{n} \sum_{i=1}^n \frac{g(x_i)f(x_i)}{q(x_i}, \text{ where } x_i \text{ is generated by } q(x)$$

These estimators have variances:
$$\operatorname{Var}_f(g(X))/n, \text{ using density } f$$ 
versus
$$\operatorname{Var}_q\!\big(g(X)\,f(X)/q(X)\big)/n, \text{ using density }q$$

Importance sampling helps when a proposal $q$ makes the weighted contributions $g(x)f(x)/q(x)$ **less variable** — i.e., **each sample carries comparable information** instead of **most samples contributing nearly zero while a few dominate the average**. 

That gives greater accuracy for the same $n$, or the same accuracy with fewer samples, regardless of whether $I$ is large or small.


## Caveat

Importance sampling is not automatically better: if ordinary Monte Carlo already has low variance, the gain may be negligible, and a poorly chosen proposal (e.g., with too-light tails, violating the $\operatorname{supp}(f) \subseteq \operatorname{supp}(q)$ condition from your slides) can increase the variance.

## About rare events

Rare events is not the only problem. Multiplying the integrand by 1,000 makes the integral 1,000 times larger, but it also multiplies the Monte Carlo standard error by 1,000 — the relative accuracy of plain Monte Carlo is unchanged. So a large integral value tells you nothing about whether ordinary sampling is efficient.

What actually matters is the **shape mismatch**: even for a moderate integral, the integrand $g(x)f(x)$ can be concentrated in a region that $f$ rarely visits (as in the rare-event case $P(Z>4.5)$ from  notes, but also whenever the integrand peaks away from the bulk of $f$). Plain Monte Carlo then wastes most of its samples. A proposal that concentrates samples where the integrand is large fixes exactly that, and the same logic applies whether the resulting integral is 0.000003 or 30.
