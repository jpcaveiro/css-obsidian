# Exercise 1-03

It is said that a random variable $X$ has a [[Pareto type 1 distribution]], with parameters $\alpha$ and $\beta$,
$$
\alpha > 0,\quad \beta > 0
$$
written as
$$
X \sim Pa(\alpha, \beta)
$$
if its probability density function has the following form:
$$
f(x \mid \alpha, \beta) = \alpha \beta^\alpha x^{-(\alpha+1)}, \quad x \ge \beta.
$$
with
$$
E(X) = \frac{\alpha \beta}{\alpha - 1}
$$
$$
Var(X) = \frac{\alpha \beta^2}{(\alpha - 1)^2(\alpha - 2)}.
$$

$$
\alpha = 3,\quad \beta = 1.5.
$$

# AI solution proposal

## Part a

Base R does **not** include built-in Pareto distribution functions like `dpareto()`, `ppareto()`, `qpareto()`, or `rpareto()`.

So, without installing `extRemes` or another package, you need to define the functions yourself.

For the Type I Pareto distribution with density

$$
f(x \mid \alpha,\beta)=\alpha \beta^\alpha x^{-(\alpha+1)}, \quad x \ge \beta
$$

you can write:

```r
dpareto <- function(x, alpha, beta) {
  ifelse(x >= beta, alpha * beta^alpha * x^(-alpha - 1), 0)
}

ppareto <- function(x, alpha, beta) {
  ifelse(x >= beta, 1 - (beta / x)^alpha, 0)
}

qpareto <- function(p, alpha, beta) {
  ifelse(p >= 0 & p <= 1, beta / (1 - p)^(1 / alpha), NA)
}

rpareto <- function(n, alpha, beta) {
  u <- runif(n)
  qpareto(u, alpha, beta)
}
```

Example with

$$
\alpha = 3,\quad \beta = 1.5
$$

```r
alpha <- 3
beta <- 1.5

dpareto(2, alpha, beta)
ppareto(2, alpha, beta)
qpareto(0.95, alpha, beta)
rpareto(10, alpha, beta)
```

If you are allowed to install a package, Pareto functions exist in packages such as:

```r

FAdist
```

For example, the `actuar` package has:

```r

```

But for your exercise, defining the functions manually is probably the expected approach.

## Part b

With `extRemes`

Yes — for part **(b)** you can use the **`extRemes`** package, but note an important detail: `extRemes` does not directly use the same Pareto Type I parameterization as your exercise. Instead, we can represent the Pareto Type I distribution as a **Generalized Pareto distribution**.

Your Pareto Type I density is

$$
f(x \mid \alpha,\beta)=\alpha \beta^\alpha x^{-(\alpha+1)}, \quad x \ge \beta.
$$

In `extRemes`, use `devd()` with `type = "GP"` and the following parameter conversion:

$$
\text{threshold}=\beta
$$

$$
\text{scale}=\frac{\beta}{\alpha}
$$

$$
\text{shape}=\frac{1}{\alpha}
$$

The `extRemes::devd()` function gives the density for extreme value distributions, including the Generalized Pareto distribution; see the package documentation here: [extRemes devd documentation](https://www.rdocumentation.org/packages/extRemes/versions/2.2/topics/devd).

```r
# Install if needed
# install.packages("extRemes")

library(extRemes)

# Function to compute Pareto Type I density using extRemes::devd()
dpareto_extremes <- function(x, alpha, beta) {
  devd(
    x,
    threshold = beta,
    scale = beta / alpha,
    shape = 1 / alpha,
    type = "GP"
  )
}
```

Now plot the density while varying `alpha` and keeping `beta` fixed.

```r
beta <- 1.5

alphas <- c(1, 2, 3, 5, 10)

x <- seq(beta, 10, length.out = 1000)

    dpareto_extremes(x, alpha = a, beta = beta)

  xlab = "x",
  ylab = "Density",
  main = expression("Pareto density varying " * alpha * " with fixed " * beta)

for (i in 2:length(alphas)) {

}

  "topright",
```


Comment for part **(b)**:

- Increasing `alpha` makes the density decrease faster, so the distribution has a lighter right tail.
- Smaller values of `alpha` produce heavier tails, meaning large values of `X` become more likely.
- Increasing `beta` shifts the support of the distribution to the right, since the density is only positive for values satisfying

$$
x \ge \beta.
$$

- At the lower bound `beta`, the density starts at

$$
f(\beta)=\frac{\alpha}{\beta}.
$$

So, for fixed `alpha`, increasing `beta` lowers the initial height of the density and moves the whole distribution to the right.

## Part c

Below is a complete solution for **(c)** using `extRemes`.

The Type I Pareto distribution in your exercise can be simulated using the Generalized Pareto distribution in `extRemes::revd()`. The parameter conversion is:

$$
\text{threshold} = \beta
$$

$$
\text{scale} = \frac{\beta}{\alpha}
$$

$$
\text{shape} = \frac{1}{\alpha}
$$

The function `revd()` in `extRemes` generates random values from extreme value distributions, including the Generalized Pareto distribution: [extRemes documentation](https://www.rdocumentation.org/packages/extRemes/versions/2.2/topics/devd).

```r
# install.packages("extRemes")
library(extRemes)

# Function to simulate Pareto Type I using extRemes
rpareto_extremes <- function(n, alpha, beta) {
  if (alpha <= 0 || beta <= 0) {
    stop("alpha and beta must be positive.")
  }
  
  revd(
    n,
    threshold = beta,
    scale = beta / alpha,
    shape = 1 / alpha,
    type = "GP"
  )
}
```

Now simulate samples for different values of `alpha`. We keep:

$$
\beta = 1.5
$$

and consider cases where the mean and/or variance do not exist.

```r
set.seed(123)

beta <- 1.5
n <- 10000

alphas <- c(0.5, 1, 1.5, 2, 3)

results <- data.frame(
  alpha = numeric(),
  beta = numeric(),
  n = numeric(),
  sample_mean = numeric(),
  sample_variance = numeric(),
  theoretical_mean = character(),
  theoretical_variance = character()
)

for (alpha in alphas) {
  
  x <- rpareto_extremes(n, alpha, beta)
  
  sample_mean <- mean(x)
  sample_variance <- var(x)
  
  theoretical_mean <- if (alpha > 1) {
    as.character(alpha * beta / (alpha - 1))
  } else {
    "Does not exist"
  }
  
  theoretical_variance <- if (alpha > 2) {
    as.character(alpha * beta^2 / ((alpha - 1)^2 * (alpha - 2)))
  } else {
    "Does not exist"
  }
  
  results <- rbind(
    results,
    data.frame(
      alpha = alpha,
      beta = beta,
      n = n,
      sample_mean = sample_mean,
      sample_variance = sample_variance,
      theoretical_mean = theoretical_mean,
      theoretical_variance = theoretical_variance
    )
  )
}

results
```

For reference, the theoretical mean is:

$$
E(X) = \frac{\alpha \beta}{\alpha - 1}
$$

which only exists when:

$$
\alpha > 1
$$

The theoretical variance is:

$$
Var(X) = \frac{\alpha \beta^2}{(\alpha - 1)^2(\alpha - 2)}
$$

which only exists when:

$$
\alpha > 2
$$

A better way to see the behaviour is to repeat the simulation for increasing sample sizes.


Comments for part **(c)**:

- When `alpha` is less than or equal to `1`, the theoretical mean does not exist. The sample mean can still be calculated in R, but it is not stable. As the sample size increases, very large observations may appear and strongly affect the mean.

- When `alpha` is greater than `1` but less than or equal to `2`, the mean exists, but the variance does not exist. In this case, the sample mean tends to be more stable, but the sample variance remains highly unstable.

- When `alpha` is greater than `2`, both the theoretical mean and variance exist. The sample mean and sample variance should become more stable as the sample size increases.

For example, with:

$$
\alpha = 1.5
$$

and

$$
\beta = 1.5
$$

the theoretical mean exists and is:

$$
E(X) = \frac{1.5 \times 1.5}{1.5 - 1} = 4.5
$$

but the variance does not exist.

With:

$$
\alpha = 3
$$

and

$$
\beta = 1.5
$$

both the mean and variance exist:

$$
E(X) = \frac{3 \times 1.5}{3 - 1} = 2.25
$$

and

$$
Var(X) = \frac{3 \times 1.5^2}{(3 - 1)^2(3 - 2)} = 1.6875
$$

So the main conclusion is: **sample means and variances can always be computed from simulated data, but they only estimate meaningful theoretical quantities when those quantities actually exist.**
