Generate values from a Binomial distribution:
$$
B(100, 0.25)
$$
(a) Determine sample characteristics of the generated values and calculate the values of the pmf and cdf at several points.

(b) Create a bar chart of 5000 generated values using:

$$
B(10, 0.25), \quad B(50, 0.25), \quad B(100, 0.25)
$$

and include in the same graph the pmf values calculated over a sequence of values, using the binomial distributions mentioned above.

(c) Consider the distribution:

$$
B(100, 0.25)
$$

Generate 5000 values from a normal distribution:

$$
N(25, \operatorname{var}=18.75)
$$

and compare the two distributions graphically.

## Chat solution proposal
Below is a complete R solution for parts (a), (b), and (c). 
## Part a

It generates the data, computes sample summaries, calculates the pmf and cdf, and produces the requested plots.

```r
# ============================================================
# Binomial distribution exercise
# ============================================================

set.seed(123)

# If ggplot2 is not installed, uncomment the next line:
# install.packages("ggplot2")

library(ggplot2)

# ============================================================
# (a) Generate values from B(100, 0.25)
# ============================================================

n <- 100
p <- 0.25
N <- 5000

x_binom <- rbinom(N, size = n, prob = p)

# Sample characteristics
sample_summary <- data.frame(
  sample_size = length(x_binom),
  mean = mean(x_binom),
  variance = var(x_binom),
  standard_deviation = sd(x_binom),
  minimum = min(x_binom),
  first_quartile = quantile(x_binom, 0.25),
  median = median(x_binom),
  third_quartile = quantile(x_binom, 0.75),
  maximum = max(x_binom)
)

print(sample_summary)

# Theoretical mean and variance
theoretical_mean <- n * p
theoretical_variance <- n * p * (1 - p)

cat("Theoretical mean:", theoretical_mean, "\n")
cat("Theoretical variance:", theoretical_variance, "\n")

# Calculate pmf and cdf at several points
points <- c(15, 20, 25, 30, 35)

pmf_cdf_table <- data.frame(
  x = points,
  pmf = dbinom(points, size = n, prob = p),
  cdf = pbinom(points, size = n, prob = p)
)

print(pmf_cdf_table)
```

The binomial mean and variance are:
$$
E(X) = np
$$
$$
\operatorname{Var}(X) = np(1-p)
$$
For this case:
$$
E(X) = 100 \times 0.25 = 25
$$
$$
\operatorname{Var}(X) = 100 \times 0.25 \times 0.75 = 18.75
$$

## Part b

Generate 5000 values from each distribution:

$$
B(10, 0.25)
$$

$$
B(50, 0.25)
$$

$$
B(100, 0.25)
$$

Then create bar charts and add the theoretical probability mass function.

```r
# ============================================================
# (b) Bar charts with empirical frequencies and theoretical pmf
# ============================================================

set.seed(123)

sizes <- c(10, 50, 100)
p <- 0.25
N <- 5000

# Generate samples
simulated_data <- data.frame()

for (s in sizes) {
  values <- rbinom(N, size = s, prob = p)
  
  temp <- data.frame(
    value = values,
    distribution = paste0("B(", s, ", 0.25)")
  )
  
  simulated_data <- rbind(simulated_data, temp)
}

# Empirical relative frequencies
empirical_freq <- as.data.frame(
  prop.table(
    table(simulated_data$value, simulated_data$distribution),
    margin = 2
  )
)

colnames(empirical_freq) <- c("value", "distribution", "relative_frequency")
empirical_freq$value <- as.numeric(as.character(empirical_freq$value))

# Theoretical pmf values
pmf_data <- data.frame()

for (s in sizes) {
  x_values <- 0:s
  
  temp <- data.frame(
    value = x_values,
    pmf = dbinom(x_values, size = s, prob = p),
    distribution = paste0("B(", s, ", 0.25)")
  )
  
  pmf_data <- rbind(pmf_data, temp)
}

# Plot
ggplot() +
  geom_col(
    data = empirical_freq,
    aes(x = value, y = relative_frequency),
    fill = "lightblue",
    color = "gray40",
    alpha = 0.7
  ) +
  geom_point(
    data = pmf_data,
    aes(x = value, y = pmf),
    color = "red",
    size = 2
  ) +
  geom_line(
    data = pmf_data,
    aes(x = value, y = pmf),
    color = "red",
    linewidth = 0.8
  ) +
  facet_wrap(~ distribution, scales = "free_x") +
  labs(
    title = "Empirical frequencies and theoretical pmf",
    x = "Value",
    y = "Probability"
  ) +
  theme_minimal()
```

In this graph:

- the blue bars represent the relative frequencies from the simulated data;
- the red points and lines represent the theoretical binomial pmf.

## Part c

Now compare:
$$
B(100, 0.25)
$$
with the normal distribution:
$$
N(25, \operatorname{var} = 18.75)
$$
Since the normal distribution uses the standard deviation, we use:
$$
\sigma = \sqrt{18.75}
$$

```r
# ============================================================
# (c) Compare B(100, 0.25) with N(25, variance = 18.75)
# ============================================================

set.seed(123)

N <- 5000

# Binomial parameters
n <- 100
p <- 0.25

# Normal parameters
mu <- 25
variance <- 18.75
sigma <- sqrt(variance)

# Generate values
x_binom <- rbinom(N, size = n, prob = p)
x_norm <- rnorm(N, mean = mu, sd = sigma)

# Put both samples in one data frame
comparison_data <- data.frame(
  value = c(x_binom, x_norm),
  distribution = c(
    rep("Binomial B(100, 0.25)", N),
    rep("Normal N(25, 18.75)", N)
  )
)

# Histogram comparison
ggplot(comparison_data, aes(x = value, fill = distribution)) +
  geom_histogram(
    aes(y = after_stat(density)),
    bins = 40,
    alpha = 0.5,
    position = "identity",
    color = "gray40"
  ) +
  labs(
    title = "Comparison between Binomial and Normal distributions",
    x = "Value",
    y = "Density"
  ) +
  theme_minimal()
```

You can also compare them using density curves:

```r
ggplot(comparison_data, aes(x = value, color = distribution, fill = distribution)) +
  geom_density(alpha = 0.25, linewidth = 1) +
  labs(
    title = "Density comparison between Binomial and Normal distributions",
    x = "Value",
    y = "Density"
  ) +
  theme_minimal()
```

The normal distribution is a good approximation here because the binomial sample size is large and the probability is not too close to 0 or 1. In this case, both distributions have the same mean and variance:

$$
\mu = 25
$$

$$
\sigma^2 = 18.75
$$
