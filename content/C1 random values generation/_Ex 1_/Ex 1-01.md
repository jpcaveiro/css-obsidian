Generate values from a Normal distribution with mean 2 and variance 4 (using language dedicated functions). 

Then solve the following items.

(a) Determine the sample characteristics: mean, median, standard deviation, and quantiles.

(b) Calculate the values of the probability density function and the cumulative distribution function at the generated points and represent them graphically.

(c) Create the histogram of the generated sample.

(d) Consider a sequence of values appropriate to the generated sample.

i. Calculate the values of the pdf of the N(2,4) distribution for that sequence and represent it graphically.

ii. In a single graph, represent the histogram of samples generated with $n = 100$ and the pdf calculated at the values of the created sequence; redo the graph using a sample of size 1000.

## Chat solution proposal

Here is a solution in **R**, assuming an initial sample size of 100.

The Normal distribution has mean 2 and variance 4, so the standard deviation is:

$$
\sigma=\sqrt{4}=2
$$

Therefore:

$$
X \sim N(2,4)
$$

In R, we should use `mean = 2` and `sd = 2`.

```r
# To always obtain the same results
set.seed(123)

# Distribution parameters
mean_pop <- 2
variance_pop <- 4
sd_pop <- sqrt(variance_pop)

# Initial sample size
n <- 100

# Generate a sample from the Normal distribution N(2,4)
x <- rnorm(n, mean = mean_pop, sd = sd_pop)

# View the first generated values
head(x)
```

## a) Sample characteristics

Calculate the mean, median, standard deviation, and quantiles of the generated sample.

```r
# Sample mean
sample_mean <- mean(x)

# Sample median
sample_median <- median(x)

# Sample standard deviation
sample_sd <- sd(x)

# Main quantiles
quantiles <- quantile(x)

# Show results
sample_mean
sample_median
sample_sd
quantiles
```

You can also present everything together:

```r
sample_summary <- list(
  mean = sample_mean,
  median = sample_median,
  standard_deviation = sample_sd,
  quantiles = quantiles
)

sample_summary
```

The quantiles given by `quantile(x)` usually correspond to:

```r
0%, 25%, 50%, 75%, 100%
```

That is: minimum, first quartile, median, third quartile, and maximum.

---

## b) Values of the density function and distribution function

The probability density function of the Normal distribution is calculated in R with `dnorm`.

The cumulative distribution function is calculated with `pnorm`.

```r
# Values of the density function at the generated points
pdf_x <- dnorm(x, mean = mean_pop, sd = sd_pop)

# Values of the cumulative distribution function at the generated points
F_x <- pnorm(x, mean = mean_pop, sd = sd_pop)

# Create a table with the values
table_b <- data.frame(
  x = x,
  density = pdf_x,
  cumulative_distribution = F_x
)

head(table_b)
```

Graphical representation of the density at the generated points:

```r
plot(
  x, pdf_x,
  main = "Values of the density function at the generated points",
  xlab = "Generated values",
  ylab = "f(x)",
  pch = 19,
  col = "blue"
)
```

Graphical representation of the cumulative distribution function:

```r
plot(
  x, F_x,
  main = "Values of the cumulative distribution function at the generated points",
  xlab = "Generated values",
  ylab = "F(x)",
  pch = 19,
  col = "darkgreen"
)
```

To make the graphs more organized, the values of `x` can be ordered:

```r
order_x <- order(x)

plot(
  x[order_x], pdf_x[order_x],
  type = "l",
  main = "Density function at the generated points",
  xlab = "x",
  ylab = "f(x)",
  col = "blue",
  lwd = 2
)

plot(
  x[order_x], F_x[order_x],
  type = "l",
  main = "Cumulative distribution function at the generated points",
  xlab = "x",
  ylab = "F(x)",
  col = "darkgreen",
  lwd = 2
)
```

## d) Appropriate sequence of values and pdf of the Normal distribution

We create a sequence between the minimum and maximum values of the sample.

```r
seq_x <- seq(
  from = min(x),
  to = max(x),
  length.out = 200
)
```

### d i) Calculate and graphically represent the pdf of the Normal distribution

```r
pdf_seq <- dnorm(seq_x, mean = mean_pop, sd = sd_pop)

plot(
  seq_x, pdf_seq,
  type = "l",
  main = "Density function of the Normal distribution N(2,4)",
  xlab = "x",
  ylab = "f(x)",
  col = "red",
  lwd = 2
)
```

The density function used is:

$$
f(x)=\frac{1}{2\sqrt{2\pi}}e^{-\frac{(x-2)^2}{8}}
$$

because:

$$
\mu=2
$$

and

$$
\sigma=2
$$
