* $T$ is a function of $n$ random variables: $X_1,\ldots,X_n$. So $T$ is also a random variable.
* $T$ is an estimator designed to "approximate" a parameter $\mu$.
* If constant $E[T]$ is $\mu$ then we say $E[T]$ is an unbiased estimator, [[bias]] must must be zero:
$$\text{bias}(T) = E[T] − \mu=0$$
