# Chapter 5 - Maximum likelihood estimation and Expectation Maximization

The Expectation-Maximization (EM) algorithm is a deterministic optimization technique introduced by Dempster, Laird, and Rubin (1977) to compute Maximum Likelihood Estimates (MLE) when dealing with unobserved or latent variables. It functions as a data augmentation method, supplementing observed variables ($Y$) with latent variables ($Z$) to simplify likelihood calculations.

The algorithm is especially useful in situations involving:
* Missing data
* Censored data
* Mixtures of distributions
