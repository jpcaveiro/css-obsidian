# Exercise 1 — Normal distribution $N(2, \sigma^2 = 4)$

The parametrisation used by R is `rnorm(n, mean, sd)`, so a variance of 4 means
`sd = 2`.

```{r ex1-params}
mu <- 2
sigma2 <- 4
sigma <- sqrt(sigma2)     # sd = 2
n <- 100
x <- rnorm(n, mean = mu, sd = sigma)
head(round(x, 4))
```

## (a) Sample characteristics

```{r ex1a}
carac <- c(
  mean   = mean(x),
  median = median(x),
  sd     = sd(x),
  var    = var(x)
)
round(carac, 4)

# quartiles and deciles
round(quantile(x), 4)
round(quantile(x, probs = seq(0, 1, by = 0.1)), 4)

# comparison with the theoretical values
data.frame(
  quantity    = c("mean", "median", "sd"),
  sample      = round(c(mean(x), median(x), sd(x)), 4),
  theoretical = c(mu, mu, sigma)
)
```

The sample values fluctuate around the theoretical ones; with $n=100$ the
standard error of the mean is $\sigma/\sqrt{n}=0.2$, which explains the
observed deviation.

## (b) p.d.f. and c.d.f. evaluated at the generated points

Because the generated points are in random order, plotting them directly gives
a scatter of points. Sorting the abscissae reveals the familiar curves.

```{r ex1b}

plot(x, Fx, pch = 20, col = "darkred",
     xlab = "x", ylab = "F(x)", main = "c.d.f. at generated points")
par(op)

     xlab = "x", ylab = "f(x)", main = "p.d.f. (sorted)")
plot(x[o], Fx[o], type = "l", lwd = 2, col = "darkred",
     xlab = "x", ylab = "F(x)", main = "c.d.f. (sorted)")
par(op)
```

```{r ex1dii, fig.width=9, fig.height=4}

  hist(xs, breaks = "FD", freq = FALSE, col = "grey90", border = "white",
       xlim = range(grid), ylim = c(0, max(f_grid) * 1.25),
```

**Comment.** With $n=1000$ the histogram tracks the theoretical density much
more closely: the Monte Carlo error decreases at rate $O(n^{-1/2})$, and the
kernel estimate becomes almost indistinguishable from $f$.

# Exercise 3 — Type I Pareto $Pa(\alpha,\beta)$

$$f(x\mid\alpha,\beta)=\alpha\beta^{\alpha}x^{-(\alpha+1)},\quad x\ge\beta,
\qquad F(x)=1-\left(\frac{\beta}{x}\right)^{\alpha}.$$

Inverting the c.d.f. gives the quantile function and hence the inversion method:

$$F^{-1}(p)=\beta(1-p)^{-1/\alpha},\qquad
X = \beta\,U^{-1/\alpha},\ U\sim U(0,1).$$

## (a) Home-made `dpareto1`, `ppareto1`, `qpareto1`, `rpareto1`

```{r ex3a-funs}
dpareto1 <- function(x, alpha = 3, beta = 1.5, log = FALSE) {
  stopifnot(alpha > 0, beta > 0)
  out <- ifelse(x >= beta, alpha * beta^alpha * x^(-(alpha + 1)), 0)
  if (log) log(out) else out
}

ppareto1 <- function(q, alpha = 3, beta = 1.5, lower.tail = TRUE) {
  stopifnot(alpha > 0, beta > 0)
  p <- ifelse(q >= beta, 1 - (beta / q)^alpha, 0)
  if (lower.tail) p else 1 - p
}

qpareto1 <- function(p, alpha = 3, beta = 1.5) {
  stopifnot(alpha > 0, beta > 0, all(p >= 0 & p <= 1))
  beta * (1 - p)^(-1 / alpha)
}

rpareto1 <- function(n, alpha = 3, beta = 1.5) {
  u <- runif(n)                 # inversion method
  beta * u^(-1 / alpha)         # U and 1-U are equally uniform
}
```

Checks with $\alpha=3$, $\beta=1.5$:


## (c) Moments when $\alpha \le 1$ and/or $\alpha \le 2$

```{r ex3c}
alpha_vec <- c(0.5, 1, 1.5, 2, 2.5, 3, 5)
N <- 20000
res <- t(sapply(alpha_vec, function(a) {
  s <- rpareto1(N, a, 1.5)
  c(alpha = a,
    sample_mean = mean(s),
    sample_var  = var(s),
    theo_mean   = if (a > 1) a * 1.5 / (a - 1) else Inf,
    theo_var    = if (a > 2) a * 1.5^2 / ((a - 1)^2 * (a - 2)) else Inf,
    max         = max(s))
}))
print(round(as.data.frame(res), 3))
```

Instability across repetitions, for three regimes:

```{r ex3c-rep}
rep_stats <- function(a, R = 8, N = 20000) {
  t(replicate(R, {
    s <- rpareto1(N, a, 1.5); c(mean = mean(s), var = var(s))
  }))
}
round(rep_stats(0.8), 2)   # no mean, no variance
round(rep_stats(1.5), 2)   # mean exists, variance does not
round(rep_stats(3.0), 2)   # both exist
```

**Comment.**

* $\alpha \le 1$: $E(X)=\infty$. The sample mean does not stabilise — it jumps
  wildly between replications and is driven by the largest observation. The Law
  of Large Numbers does not apply.
* $1 < \alpha \le 2$: the mean exists and the sample mean converges, but
  $\operatorname{Var}(X)=\infty$, so the sample variance is erratic and grows
  with $n$; the CLT in its usual form fails (no finite-variance normal limit).
* $\alpha > 2$: both moments are finite and the sample values are close to the
  theoretical ones, with the usual $O(n^{-1/2})$ error.

The finite sample statistics are *always* finite, which is exactly the trap:
a finite number never signals by itself that the underlying moment diverges —
only its behaviour as $n$ and across replications does.

# Exercise 4 — Logistic distribution $Lo(\alpha=1, \beta=2)$

With $z=(x-\alpha)/\beta$,

$$f(x)=\frac{\beta^{-1}e^{-z}}{(1+e^{-z})^{2}},\qquad
F(x)=\frac{1}{1+e^{-z}},\qquad
F^{-1}(p)=\alpha+\beta\log\!\frac{p}{1-p}.$$

Again inversion gives the generator $X=\alpha+\beta\,\mathrm{logit}(U)$.

```{r ex4-funs}
dlogis1 <- function(x, alpha = 1, beta = 2) {
  stopifnot(beta > 0)
  z <- (x - alpha) / beta
  e <- exp(-z)
  e / (beta * (1 + e)^2)
}

plogis1 <- function(q, alpha = 1, beta = 2) {
  stopifnot(beta > 0)
  1 / (1 + exp(-(q - alpha) / beta))
}

qlogis1 <- function(p, alpha = 1, beta = 2) {
  stopifnot(beta > 0, all(p > 0 & p < 1))
  alpha + beta * log(p / (1 - p))
}

rlogis1 <- function(n, alpha = 1, beta = 2) {
  u <- runif(n)
  alpha + beta * log(u / (1 - u))     # inversion method
}
```

# Exercise 5 — Rejection method for $Be(2,2)$, $f(x)=6x(1-x)$

Proposal $g(x)=1$ on $(0,1)$. We need $c$ with $f(x)\le c\,g(x)$:
$\max_x f(x)=f(1/2)=3/2$, so $c=3/2$. The acceptance probability is $1/c=2/3$
and the number of proposals until one acceptance is geometric with mean $c$.

```{r ex5-c}
f_beta22 <- function(x) ifelse(x > 0 & x < 1, 6 * x * (1 - x), 0)
cc <- 3 / 2          # = f(1/2)
1 / cc               # acceptance probability
```

## (a) Expected number of $U(0,1)$ numbers for 1000 values

Each trial uses **two** uniforms (one for the candidate $Y$, one for the
acceptance test $U$). So:

```{r ex5a}
n5 <- 1000
exp_iter <- n5 * cc            # expected number of iterations (trials)
exp_unif <- 2 * exp_iter       # expected number of U(0,1) numbers
c(expected_iterations = exp_iter, expected_uniforms = exp_unif)
```

On average $1000 \times 1.5 = 1500$ iterations, i.e. about **3000** uniform
pseudo-random numbers.

## (b) Generating 1000 values with an iteration counter

```{r ex5b}
rbeta22_rejection <- function(n, c_const = 3 / 2) {
  out   <- numeric(n)
  k     <- 0L    # accepted
  iter  <- 0L    # trials
  while (k < n) {
    iter <- iter + 1L
    y <- runif(1)                   # candidate from g = U(0,1)
    u <- runif(1)
    if (u <= f_beta22(y) / (c_const * 1)) {   # accept
      k <- k + 1L
      out[k] <- y
    }
  }
  list(x = out, iter = iter, uniforms = 2L * iter,
       acc_rate = n / iter)
}

set.seed(123)
sim <- rbeta22_rejection(n5)
c(iterations = sim$iter, uniforms = sim$uniforms,
  expected_iterations = exp_iter,
  acceptance_rate = round(sim$acc_rate, 4),
  theoretical_rate = round(1 / cc, 4))
```

The observed number of iterations is close to the expected 1500, and the
empirical acceptance rate is close to $2/3$.

# Exercise 6 — Mixtures of Gamma distributions

A mixture $\sum_i w_i f_i$ is simulated in two steps: draw the component
index $I$ with probabilities $w_i$, then draw from $f_I$ (composition method).

## (a) $0.3\,Ga(1.5,3) + 0.7\,Ga(5,3)$

We use the (shape, rate) parametrisation, `rgamma(n, shape, rate)`.

```{r ex6a}
n6 <- 10000
w      <- c(0.3, 0.7)
shapes <- c(1.5, 5)
rate   <- 3

comp <- sample(seq_along(w), size = n6, replace = TRUE, prob = w)
xm1  <- rgamma(n6, shape = shapes[comp], rate = rate)

# theoretical mixture density
dmix1 <- function(x) w[1] * dgamma(x, shapes[1], rate) +
                     w[2] * dgamma(x, shapes[2], rate)

round(c(sample_mean = mean(xm1),
        theoretical_mean = sum(w * shapes / rate),
        sample_var = var(xm1)), 4)
```


The mixture is right-skewed with a shoulder on the left contributed by the

## (b) $\sum_{i=1}^{5}\theta_i\,f_{Ga(3,\theta_i)}$

Here the same $\theta_i$ play both roles: mixing weights **and** rate of the
$i$-th gamma component (shape fixed at 3). The weights sum to 1.

```{r ex6b}
theta <- c(0.1, 0.2, 0.2, 0.3, 0.2)
sum(theta)             # = 1, so it is a proper mixture
shape6 <- 3

comp2 <- sample(seq_along(theta), size = n6, replace = TRUE, prob = theta)
xm2   <- rgamma(n6, shape = shape6, rate = theta[comp2])

dmix2 <- function(x)
  rowSums(sapply(seq_along(theta),
                 function(i) theta[i] * dgamma(x, shape6, rate = theta[i])))

round(c(sample_mean = mean(xm2),
        theoretical_mean = sum(theta * shape6 / theta),   # weight_i * shape/rate_i
        sample_median = median(xm2)), 4)
```

Note the theoretical mean is $\sum_i \theta_i \cdot \frac{3}{\theta_i}
= 3 \times 5 = 15$ only because each weight cancels its own rate — a nice
particular feature of this parametrisation.


# Exercise 7 — Beta-Binomial $Betabin(n,\alpha,\beta)$

## (a) The Beta-Binomial as a Binomial–Beta mixture

Let $X\mid Y=y \sim B(n,y)$ and $Y\sim Be(\alpha,\beta)$. Then

$$f(x) = \int_0^1 \binom{n}{x} y^{x}(1-y)^{n-x}\,
\frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)}
y^{\alpha-1}(1-y)^{\beta-1}\,dy
= \binom{n}{x}\frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)}
\int_0^1 y^{\alpha+x-1}(1-y)^{\beta+n-x-1}\,dy .$$

The integral is the Beta function $B(\alpha+x,\ \beta+n-x)$, hence

$$f(x)=\binom{n}{x}\frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)}\,
\frac{\Gamma(\alpha+x)\Gamma(\beta+n-x)}{\Gamma(\alpha+\beta+n)}
= c\binom{n}{x}\Gamma(\alpha+x)\Gamma(\beta+n-x),$$

with $c=\dfrac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)\Gamma(\alpha+\beta+n)}$,
which is exactly the stated p.m.f. $\square$

This derivation *is* the generation algorithm: draw $Y\sim Be(\alpha,\beta)$,
then $X\mid Y \sim B(n,Y)$.

Numerical confirmation of the identity:

```{r ex7a}
al7 <- 10; be7 <- 22; n7 <- 4

dbetabin <- function(x, alpha, beta, n) {
  cst <- exp(lgamma(alpha + beta) - lgamma(alpha) - lgamma(beta) -
             lgamma(alpha + beta + n))
  cst * choose(n, x) * gamma(alpha + x) * gamma(beta + n - x)
}

# via numerical integration of the mixture representation
dbetabin_int <- function(x, alpha, beta, n)
  sapply(x, function(k)
    integrate(function(y)
      choose(n, k) * y^k * (1 - y)^(n - k) * dbeta(y, alpha, beta),
      0, 1)$value)

xx <- 0:n7
data.frame(
  x         = xx,
  closed    = round(dbetabin(xx, al7, be7, n7), 8),
  integral  = round(dbetabin_int(xx, al7, be7, n7), 8)
)
sum(dbetabin(xx, al7, be7, n7))   # = 1
```

# Exercise 8 — Bivariate uniform on $\{0<x<y<1\}$

$$f_{(X,Y)}(x,y)=2,\qquad 0<x<y<1 .$$

## Analytical preparation

Marginal of $Y$: $f_Y(y)=\int_0^y 2\,dx = 2y$, $0<y<1$, i.e. $Y\sim Be(2,1)$
with $F_Y(y)=y^2$ and $F_Y^{-1}(u)=\sqrt{u}$.

Conditional: $f_{X\mid Y}(x\mid y)=\frac{2}{2y}=\frac1y$, so
$X\mid Y=y \sim U(0,y)$.

Hence the **conditional (composition) method**:
$$Y=\sqrt{U_1},\qquad X = Y\,U_2 .$$

Two alternatives are shown for comparison: rejection over the unit square, and
the order-statistic trick $(X,Y)=(\min(U_1,U_2),\max(U_1,U_2))$ — since the
pair of order statistics of two independent uniforms has exactly density 2 on
$0<x<y<1$.

```{r ex8-funs}
# Method 1: conditional / inversion
r_biv_cond <- function(n) {
  y <- sqrt(runif(n))
  x <- y * runif(n)
  cbind(x = x, y = y)
}

# Method 2: rejection on the unit square (acceptance probability 1/2)
r_biv_rej <- function(n) {
  out <- matrix(NA_real_, n, 2, dimnames = list(NULL, c("x", "y")))
  k <- 0L; iter <- 0L
  while (k < n) {
    iter <- iter + 1L
    u <- runif(2)
    if (u[1] < u[2]) { k <- k + 1L; out[k, ] <- u }
  }
  attr(out, "iter") <- iter
  out
}

# Method 3: order statistics of two uniforms
r_biv_ord <- function(n) {
  u1 <- runif(n); u2 <- runif(n)
  cbind(x = pmin(u1, u2), y = pmax(u1, u2))
}
```

## Samples of different sizes

## Checking the three methods agree

```{r ex8-check}
set.seed(7)
n8 <- 20000
S1 <- r_biv_cond(n8)
S2 <- r_biv_rej(n8)
S3 <- r_biv_ord(n8)

theo <- c(E_X = 1/3, E_Y = 2/3, Var_X = 1/18, Var_Y = 1/18, Cov = 1/36)
summ <- function(S) c(E_X = mean(S[, 1]), E_Y = mean(S[, 2]),
                      Var_X = var(S[, 1]), Var_Y = var(S[, 2]),
                      Cov = cov(S[, 1], S[, 2]))
round(rbind(conditional = summ(S1), rejection = summ(S2),
            order_stat = summ(S3), theoretical = theo), 5)

# rejection cost: expected 2n iterations
c(iterations = attr(S2, "iter"), expected = 2 * n8)

# all points respect the support
c(cond_ok = all(S1[, 1] < S1[, 2]), rej_ok = all(S2[, 1] < S2[, 2]),
  ord_ok = all(S3[, 1] <= S3[, 2]))
```
