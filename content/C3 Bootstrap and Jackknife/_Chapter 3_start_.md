
# Chapter 3 - Bootstrap and jackknife resampling techniques

Bootstrap and jackknife resampling techniques are two methods that can be used as an alternative to the Monte Carlo methods mentioned above **when no statistical model is available** for describing data, i.e., $X \sim \text{unknown or no model chosen}$.
